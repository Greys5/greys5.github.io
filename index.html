PLATFORM / IDENTITY + SECURITY⚿
FIELD NOTE / 002

Who gets access?

Keycloak, machine-to-machine access, and Terraform-managed identity. Making permissions explicit and access repeatable, with security in the foundation.

KeycloakTerraformIAM
A closer look +

A login page loading isn’t proof that authentication works. How do access configuration, real login flows, and monitoring signals agree?

PLATFORM / OPERATIONS⌗
FIELD NOTE / 003

Follow the signals.

Kubernetes operations, declarative delivery, and observability. Understanding what happens when scaling, controllers, and application behavior meet.

AWS / EKSHelm / Argo CDDatadog
A closer look +

Which controller owns this setting? What do the logs actually show? A hypothesis is a useful starting point. A controlled check tells you whether it holds.

PERSONAL / CLOUD COSTS · POC✦
FIELD NOTE / 004

Costellation

Where’s the AWS bill going? A personal, read-only dashboard to explore costs across accounts and services, check cost allocation tags, and export reports. Still a proof of concept, with validation in progress.

BackstageFastAPIAWS Cost Explorer
A closer look +

How do you make AWS spending easier to understand without changing cloud resources? Costellation brings account inventory, cost filters, tag coverage, and CSV exports into one local interface. Built on Backstage with a FastAPI backend.

Platform work is described at a high level. Internal details stay internal.
