I’m a platform engineer in Argentina. My work is mostly cloud infrastructure, Kubernetes, automation, identity, and security.

I like getting into how things work. If something breaks, I want to know why. If I’m doing the same thing again, I’m already wondering whether I can automate it. And “that’s the default” isn’t much of an explanation.

I also make things to learn, play with creative coding, and see what happens when I connect ideas that don’t obviously belong together.

PERSONAL / CLOUD COSTS · POC✦
FIELD NOTE / 004

Costellation

Where’s the AWS bill going? A personal, read-only dashboard to explore costs across accounts and services, check cost allocation tags, and export reports. Still a proof of concept, with validation in progress.

BackstageFastAPIAWS Cost Explorer
A closer look +

How do you make AWS spending easier to understand without changing cloud resources? Costellation brings account inventory, cost filters, tag coverage, and CSV exports into one local interface. Built on Backstage with a FastAPI backend.

MY DELIVERY CYCLE

  1. 01

    Figure out what’s needed.

    Choose the cloud, map dependencies and work out what needs to change.

  2. 02

    Put the base together.

    Set up infrastructure, containers and configuration.

  3. 03

    See if it holds up.

    Test changes and check for vulnerabilities before moving on.

  4. 04

    Get it running.

    Run the pipeline, review the result and deploy.

  5. 05

    Keep it running.

    Keep workloads running and adjust capacity when needed.

  6. 06

    Check access, security and logs.

    Review permissions, investigate errors and check what needs fixing.
