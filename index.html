01 / THE HUMAN↓

Less “trust me.”
More “let’s find out.”

I’m a platform engineer based in Argentina. I work with cloud infrastructure, Kubernetes, automation, identity, and security.

I like understanding how the pieces fit together. If something breaks, I want the reason. If a task keeps coming back, I want a better way to do it. And if a default doesn’t make sense, I’m going to question it.

Outside infrastructure, that same curiosity turns into creative coding, interactive visuals, and learning projects. Different rabbit holes. Same brain.

PERSONAL / LEARNING⎈
FIELD NOTE / 001

Kubi

Kubernetes makes more sense when you can try things. A learning project with browser simulations and CLI exercises, built around understanding what actually happens.

KubernetesBrowser simulations
The question behind it +

How do you help someone understand a system, rather than memorize a command? Feedback on wrong and incomplete commands is part of the lesson.

PLATFORM / IDENTITY + SECURITY⚿
FIELD NOTE / 002

Who gets access?

Keycloak, machine-to-machine access, and Terraform-managed identity. Making permissions explicit and access repeatable, with security in the foundation.

KeycloakTerraformIAM
The question behind it +

A login page loading isn’t proof that authentication works. How do access configuration, real login flows, and monitoring signals agree?

PLATFORM / OPERATIONS⌗
FIELD NOTE / 003

Follow the signals.

Kubernetes operations, declarative delivery, and observability. Understanding what happens when scaling, controllers, and application behavior meet.

AWS / EKSHelm / Argo CDDatadog
The question behind it +

Which controller owns this setting? What do the logs actually show? A hypothesis is a useful starting point. A controlled check tells you whether it holds.

PERSONAL / CREATIVE CODING✳
FIELD NOTE / 004

What if sound moved?

Interactive visuals and audio-driven experiments. Connecting microphone input to motion, and turning the browser into something you can play with.

Three.jsJavaScriptWeb Audio
The question behind it +

How does sound become motion? The interesting work is in the mapping—and in what happens when a technical input starts to feel expressive.
